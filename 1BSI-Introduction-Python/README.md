# Exercices Python pour SUDO

Ce pack contient douze exercices progressifs pour débuter en Python. Les noms de fonctions sont en anglais, les consignes sont en français et chaque algorithme utilise le style Mermaid inspiré de Flowgorithm.

Copiez le dossier `Exercises` dans les Documents de l’étudiant, puis ouvrez-le depuis SUDO avec **SUDO : ouvrir Exercises**.

```text
Exercises/
└── Python-Basics/
    ├── 01-double-number/
    ├── 02-temperature-conversion/
    ├── 03-rectangle-area/
    ├── 04-number-sign/
    ├── 05-even-number/
    ├── 06-maximum-of-three/
    ├── 07-sum-to-n/
    ├── 08-multiplication-table/
    ├── 09-factorial/
    ├── 10-average/
    ├── 11-count-vowels/
    └── 12-palindrome/
```

Les solutions sont automatiquement créées par SUDO dans `MesSolutions`. Ne modifiez pas `starter.py` ou `tests.py` directement.

| Nº | Exercice | Fonction |
| ---: | --- | --- |
| 1 | Doubler un nombre | `double_number(number)` |
| 2 | Convertir une température | `celsius_to_fahrenheit(celsius)` |
| 3 | Aire d’un rectangle | `rectangle_area(length, width)` |
| 4 | Déterminer le signe | `number_sign(number)` |
| 5 | Nombre pair ou impair | `is_even(number)` |
| 6 | Maximum de trois nombres | `maximum_of_three(a, b, c)` |
| 7 | Somme de 1 à n | `sum_to_n(n)` |
| 8 | Table de multiplication | `multiplication_table(number)` |
| 9 | Factorielle | `factorial(n)` |
| 10 | Moyenne | `average(values)` |
| 11 | Compter les voyelles | `count_vowels(text)` |
| 12 | Palindrome | `is_palindrome(text)` |

L’exercice 3 effectue uniquement le calcul `length × width` et ne demande aucune gestion d’exception.
